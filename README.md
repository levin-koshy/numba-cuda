# CUDA Python with Numba

A learning repository containing notebooks, exercises, and supporting Python
files for GPU programming with Numba.

## Contents

- `section1/`: introduction to Numba, CPU compilation, GPU ufuncs, and data transfers.
- `section2/`: custom CUDA kernels, grid-stride loops, atomic operations, and debugging.
- `section3/`: multidimensional grids, memory access, and shared memory.

Each section includes a Jupyter notebook and supporting images and exercise files.
Solution examples and assessment files are included where present in the course materials.

## Working with the notebooks

Open the notebooks in Jupyter and follow the sections in order. GPU exercises
require an NVIDIA GPU and a compatible CUDA and Numba environment. The materials
use an older course environment; package versions are not pinned here, and
compatibility with current environments has not been validated.

Some links and assessment instructions refer to the original hosted course
environment. Navigate to local supporting files through Jupyter when those
links do not resolve. Hosted assessment services are not included.
